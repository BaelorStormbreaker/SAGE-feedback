# SAGE feedback

Bug reports and ideas for **SAGE (Stat Analysis & Gear Evaluator)**, a gearing advisor addon for WoW: Forever.

This repository holds reports only. Get SAGE from CurseForge (author: BaelorStormbreaker).

## Report a bug or suggest an idea
**[Start a new report here](https://github.com/BaelorStormbreaker/SAGE-feedback/issues/new/choose)**

1. Click the link above (or **Issues > New issue** at the top of this page).
2. Choose **Bug report** or **Idea or suggestion**.
3. For bugs: in game, click SAGE's **Report** button (or type `/sage report`), copy the text and paste it into the form. It tells us your SAGE version, class, level, active route and the last error, so we can find the problem faster.

You need a free GitHub account to post.

## What happens next
1. Reports are labeled (bug or idea) and checked for duplicates. We may ask a question.
2. Bug fixes go out first as a **Beta** file on CurseForge for testing, then as a full release.
3. When a fix or idea ships, the report gets a reply with the version, and is closed.

Before reporting, check the FAQ on the CurseForge page: it covers "% vs pts", why an item isn't shown as an upgrade, set notes and slow first Auction House scans.

Please keep reports about SAGE, and leave other players' names and chat out of screenshots.
